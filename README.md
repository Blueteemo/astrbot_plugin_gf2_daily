# 少前2 社区助手

《少女前线2：追放》社区每日任务自动化插件，支持签到、浏览/点赞/分享帖子、积分兑换。

## 命令

| 命令 | 说明 |
|------|------|
| `/gf2` | 执行完整每日任务（浏览+点赞+分享+兑换+签到） |
| `/gf2 签到` | 仅签到 |
| `/gf2 状态` | 查看积分、等级 |
| `/gf2 兑换` | 查看可兑换商品列表 |
| `/gf2 兑换 <ID>` | 手动兑换指定商品 |

## 设置

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 社区账号 | 手机号 | - |
| 社区密码 | 密码 | - |
| 兑换：情报拼图×20 | 每日2次，每次30积分 | ✅ 开启 |
| 兑换：萨狄斯金×500 | 每日1次，每次30积分 | ✅ 开启 |
| 兑换：战场报告×500 | 每日1次，每次30积分 | ✅ 开启 |
| 兑换：解析图纸×500 | 每日1次，每次30积分 | ✅ 开启 |
| 兑换：基原信息核×1 | 每月1次，每次100积分 | ✅ 开启 |
| 自动兑换限时/特殊商品 | 兑换页面中的限时商品 | ✅ 开启 |
| 输出已兑换商品的兑换日志 | 输出兑换结果 | ❌ 关闭 |

## 每日任务流程

1. **登录** — 使用账号密码登录社区
2. **检查任务** — 查看今日未完成的浏览/点赞/分享任务
3. **执行任务** — 从官方板块获取帖子，完成未完成任务
4. **兑换商品** — 按优先级（限时 > 月刷新 > 日刷新）尝试兑换
5. **签到** — 签到并输出当日奖励

## 商品兑换优先级

限时商品（终身/特殊）> 月刷新商品 > 日刷新商品

积分数相同时，优先兑换情报拼图（可交易道具）。
兑换过程中遇到积分不足时自动停止，保留剩余积分。

## 安装

1. 下载 ZIP 包
2. 在 AstrBot 管理面板上传安装
3. 填写社区账号和密码
4. 按需开启兑换项目和自动兑换选项
